# doc-of-journey/README.md

Development memory for CarryForward. Record only work that actually happened; never backfill.

- `daily/` — one chronological note per actual work session: what was attempted, exact commands, observed results, failures, unresolved work.
- `decisions/` — numbered, durable decision records (`NNNN-short-title.md`): date, status, context, decision, alternatives, consequences. Decisions may be superseded; the old record stays and points to its successor.
- `topics/errors.md` — append-only catalog of errors that cost more than five minutes. Search it before debugging anything.
- `topics/tactics.md` — only proven, reusable techniques that actually saved time.
- `topics/in-progress.md` — current focus pointer; update on phase changes.

Session-end procedure: `weeks/memory-protocol.md`.
